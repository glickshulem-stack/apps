Sign in once

Studio needs a key from your GitHub account so it can put apps into Play Hub. You only do this once on each device, and the key stays on this device.

  1. Tap Make a key on GitHub below. Sign in to GitHub if it asks.
  2. Next to Expiration, choose No expiration.
  3. Scroll to the bottom and press Generate token.
  4. Copy the long key that starts with ghp_, come back here and paste it below.
