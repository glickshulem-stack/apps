# Quillsong — notes

## What it does
A book reader with lifelike page turns and two pages side by side on the tablet. Opens PDF, EPUB, Word and text files and reads them aloud in a natural offline voice, highlighting each word.

- This is Su's own app with its own signing key. Its source code is not in this repo (only the icon is here).
- New versions are added through App Vault Studio (+ Add app).

## Current version
1.9.0

## Su's decisions
- Voice: Kokoro "Hannah", full quality. Su did not want any of the Piper voices.
- "1x" speed is a little slower than normal (Su's wish).
- Settings for a cooler tablet: Voice power (Gentle, Normal, Fast) and Prepare ahead (20 s, 1 min, 5 min).
- The graphics-chip voice option was removed because it ran hotter.

## Known bugs
- The tablet can get warm while reading aloud for a long time.
